# 新传研背 版本路线图（ROADMAP）

> ⚠️ 已过时（2026-10-02 更新）：本文记录的是 V4.0–V6.0 历史规划，当前阶段与发布节奏以 [PRD.md](./PRD.md) 与 [落地计划-GitHub公测.md](./落地计划-GitHub公测.md) 为准。

## V4.0（当前 — 2026-09-10）

- ✅ Monorepo 架构标准化
- ✅ apps/mobile + apps/admin + packages/content 分层
- ✅ 唯一题库数据源
- ✅ 版本记录目录（versions/）
