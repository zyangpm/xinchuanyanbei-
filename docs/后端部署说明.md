## 一、本地怎么跑起来

需要开**两个**服务（先启动后端，再启动前端）：

```bash
# ① 后端（端口 3000，用 Node 自带的 http + sqlite，无需额外安装依赖）
cd apps/server
node src/server.js

# ② 前端网页版（端口 8081，另开一个终端）
node apps/mobile/start-server.js
```

然后浏览器访问：
- 学生端：http://localhost:8081
- 管理后台：http://localhost:8081/admin/

> 数据存在 `apps/server/data/xinchuan.db`（自动创建，已加入 .gitignore）。

## 二、前后端怎么连的

| 环节 | 说明 |
|---|---|
| 后台发/改/删题 | 自动推送到后端 `/api/questions/sync`（失败静默，不影响本地） |
| 学生端打开页面 | 自动从后端 `/api/questions` 拉取已发布题目并合并显示 |

**后端地址配置**：默认写死 `http://localhost:3000/api`；上线时在页面里加一行即可切换（无需改代码逻辑）：
```html
<script>window.XC_API_BASE = 'https://你的域名/api';</script>
```

## 三、上云部署步骤（准备好服务器后）

1. **租一台云服务器**（Linux，1核2G 起步即可，学生机/活动机更便宜）
2. **装 Node.js（>= 22）**：
   ```bash
   # 以 Ubuntu 为例
   curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
   sudo apt-get install -y nodejs
   ```
3. **上传项目**（git clone 或 scp）
4. **起后端 + 进程守护**（PM2 自动重启、开机自启）：
   ```bash
   npm i -g pm2
   cd apps/server && pm2 start src/server.js --name xinchuan-api
   pm2 save && pm2 startup
   ```
5. **起前端静态服务**：同样用 pm2 跑 `apps/mobile/start-server.js`，或交给 Nginx 直接托管静态文件
6. **Nginx 反向代理 + 域名 + HTTPS**：
   - `/` → 前端静态（8081）
   - `/api/` → 后端（3000）
   - 用 Let's Encrypt 免费证书开 HTTPS
7. **前端指向域名**：设置 `window.XC_API_BASE = 'https://你的域名/api'`

## 四、数据备份（重要）

SQLite 就是一个文件，定时复制即可：
```bash
# 每天凌晨备份一份，保留 7 天
0 2 * * * cp /path/apps/server/data/xinchuan.db /path/backup/xinchuan-$(date +\%F).db
```

## 五、常用排查

| 现象 | 原因/处理 |
|---|---|
| 学生端看不到后台发的题 | 检查后端是否在跑（`/api/health`）；检查 `window.XC_API_BASE` 指向对不对 |
| 网页改了没生效 | 浏览器/PWA 缓存，按 `Ctrl+F5` 强刷；或清 Service Worker |
| 后端报端口占用 | 改环境变量 `PORT=3001 node src/server.js` |
| 桌面版（exe）不联后端 | 正常：桌面版走本地共享文件，云端共享仅网页版生效 |
