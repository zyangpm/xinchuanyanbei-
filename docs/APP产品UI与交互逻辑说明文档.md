# 《新传研背》APP 产品 UI 与交互逻辑说明文档

> 本文档客观描述当前 v1.0.0 版本已实现的功能与交互，供产品评审使用。

---

## 一、APP 整体结构

### 1. APP 名称
**新传研背**

### 2. 当前版本定位
- 版本号：v1.0.0
- 平台：Electron 桌面应用（Windows exe / macOS dmg）
- 定位：新传考研背诵学习工具，面向新闻传播学考研考生，提供名词解释、简答题、论述题的框架化学习与背诵辅助
- 当前阶段：交互功能验证版，非最终发布版

### 3. 核心功能模块列表

| 模块 | 说明 |
|------|------|
| 启动页 | 应用启动闪屏动画 |
| 登录系统 | 密码登录、验证码登录、第三方登录（微信/QQ/微博） |
| 首页 | 用户信息卡、继续学习入口、核心功能入口 |
| 知识库 | 名词解释词条列表、搜索、教材分类筛选、题型筛选 |
| 名词解释详情 | 视频播放、五段式知识框架、分层串记树、AI助记社区、AI视频生成 |
| 简答题详情 | 答题框架、真题设问变式、答案内容、辅助记忆（含5种自测模式） |
| 论述题详情 | 答题框架、真题设问变式、答案内容、辅助记忆（含5种自测模式） |
| 收藏 | 收藏内容列表、题型筛选 |
| 个人中心 | 账号管理、学习偏好设置、AI模型管理、系统设置 |

### 4. APP 整体页面结构（页面层级关系）

```
启动页 (splash.html)
  └── 首页 (index.html) ── 底部导航 ──┬── 知识库 (knowledge.html)
                                      ├── 收藏 (collections.html)
                                      └── 首页 (index.html)
  
登录页 (login.html) ──登录成功──→ 首页

首页 ── 用户卡片 ──→ 个人中心 (profile.html)
首页 ── 继续学习卡 ──→ 名词解释详情 (noun-detail.html)
首页 ── 名词解释入口 ──→ 知识库 (knowledge.html)
首页 ── 简答题入口 ──→ 简答题详情 (short-detail.html)
首页 ── 论述题入口 ──→ 论述题详情 (essay-detail.html)

知识库 ── 点击词条 ──→ 名词解释详情 (noun-detail.html?term=xxx)

名词解释详情 ── 上/下一个 ──→ 名词解释详情
简答题详情 / 论述题详情 ── 返回 ──→ 知识库
```

底部导航为全局导航，在首页、知识库、收藏页之间切换。详情页和个人中心页无底部导航，通过顶部返回按钮回退。

- AI视频生成按钮（仅"沉默的螺旋"显示）："生成AI记忆视频"

## 三、页面交互逻辑

### 启动页
| 操作 | 结果 |
|------|------|
| 无 | 2秒后自动加载首页 |

### 登录页
| 操作 | 结果 |
|------|------|
| 点击Tab | 切换密码登录/验证码登录表单 |
| 输入手机号+密码，点击登录 | 校验手机号11位、密码≥6位，通过后存储登录状态，跳转首页 |
| 点击获取验证码 | 校验手机号，60秒倒计时，弹窗提示验证码（测试码1234） |
| 输入验证码，点击登录 | 校验验证码=1234，通过后跳转首页 |
| 点击微信/QQ/微博图标 | 校验协议勾选，弹窗"正在跳转X授权页面"，1.5秒后模拟登录成功跳转首页 |
| 未勾选协议点击登录 | 弹窗警告"请先阅读并同意用户协议和隐私政策" |

### 首页
| 操作 | 结果 |
|------|------|
| 点击用户信息卡 | 跳转个人中心 |
| 点击继续学习卡 | 跳转名词详情（term=新闻价值） |

### 知识库

| 点击教材分类标签 | 按教材筛选词条：全部显示所有，传播学原理只显示对应词条，无匹配的分组隐藏 |

### 名词解释详情
| 操作 | 结果 |
|------|------|

## 四、核心学习流程

### 流程一：名词解释学习
```
打开APP → 启动页(2s) → 首页
  → 点击"名词解释"入口 → 知识库
  → 点击目标词条（如"沉默的螺旋"）→ 名词解释详情
  → 默认看视频Tab
    → 点击播放按钮观看视频
    → 点击"生成AI记忆视频"生成专属视频
  → 切换到"知识框架"Tab → 阅读五段式框架
  → 切换到"分层串记"Tab → 浏览知识树
  → 切换到"AI助记"Tab → 查看社区记忆口诀
  → 点击状态按钮标记掌握程度（不会/模糊/认识）
  → 点击"上一个"/"下一个"切换词条
```

### 流程二：简答题/论述题背诵
```
首页 → 点击"简答题"/"论述题"入口 → 详情页
  → 默认看"答题框架"Tab → 了解总分结构
  → 切换"真题设问变式"→ 了解题目变化
  → 切换"答案内容"→ 阅读完整答案
  → 切换"辅助记忆"
    → 选择自测模式（拖拽还原/填空记忆/框架默写/红膜背书/闪卡模式）
    → 完成自测 → 点击"完成自测"
    → 弹窗选择掌握程度
  → 查看记忆分享社区 → 获取他人记忆方法
  → 点击TTS按钮听读答案
```

### 流程三：收藏复习
```
首页 → 点击底部"收藏" → 收藏页
  → 点击题型筛选 → 查看对应类型收藏
  → 点击词条 → 进入详情复习
```

## 五、AI 功能说明

### 1. AI视频生成
- **入口**：名词解释详情页 - 视频Tab - "生成AI记忆视频"按钮（仅"沉默的螺旋"词条显示）
- **用户输入**：视频内容描述（自动填充提示词）、选择API（DeepSeek/ChatGPT/Claude）、视频时长
- **AI返回**：当前为模拟生成，2秒后提示生成成功，按钮变为绿色"视频生成成功 ✓"
- **参与学习**：生成后可点击播放按钮观看

### 2. AI模型切换
- **入口**：名词解释详情页右侧悬浮"切换AI模型"按钮
- **功能**：选择AI模型（DeepSeek/ChatGPT）、配置API密钥、设置生成画质和文字详细程度
- **状态**：弹窗可交互，保存设置关闭弹窗，实际API调用未接入

### 3. AI助记（社区分享）
- **入口**：名词解释详情页 - AI助记Tab
- **内容**：展示其他用户分享的记忆口诀和背诵技巧
- **交互**：可发布自己的记忆方法（提交审核），可点赞

### 4. TTS语音朗读
- **入口**：简答题/论述题详情页 - 辅助记忆Tab - 朗读栏
- **功能**：使用浏览器原生Web Speech API朗读答案内容
- **交互**：点击播放/暂停按钮切换，朗读进度条显示

## 七、当前版本限制

### 功能简单
1. **视频播放**：无真实视频文件，仅模拟进度条5秒动画
2. **AI功能**：所有AI相关功能均为模拟，无真实API调用
3. **登录系统**：无后端验证，任意手机号+6位密码即可登录，第三方登录为模拟跳转
4. **数据存储**：全部使用localStorage本地存储，无服务端同步，换设备数据丢失
5. **搜索范围**：仅搜索知识库页面12个名词解释，不覆盖简答题和论述题
6. **内容数量**：简答题和论述题各仅1道示例，知识库仅12个名词

### 仅展示（无完整闭环）
1. **记忆分享社区**：发布的内容存入localStorage但不会在当前页面列表中显示，无审核流程，无评论功能
2. **笔记功能**：可保存笔记但无法查看历史笔记，笔记不与具体词条关联
3. **收藏功能**：收藏列表为固定预设数据，详情页点击收藏按钮不联动收藏列表
4. **学习进度**：首页显示"连续背诵5天""累计842词条"为固定数字，不随实际学习更新
5. **状态标记**：标记不会/模糊/认识后仅弹窗提示，不联动学习进度或复习队列
6. **自测评分**：拖拽排序无正误判定，填空无对错反馈，框架默写无对比评分

### 无完整闭环
1. **学习闭环缺失**：无学习计划、无复习提醒推送（仅有开关）、无学习数据统计
2. **内容管理闭环缺失**：上传资料弹窗有文件选择但无解析生成题库逻辑
3. **社交闭环缺失**：记忆分享无评论、无回复、无用户主页
4. **多端同步缺失**：无账号体系后端，无云同步
5. **通知系统缺失**：背诵提醒仅有开关，无实际通知推送机制
