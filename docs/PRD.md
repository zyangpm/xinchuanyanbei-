## 1. 产品概述

新传研背是一款面向新闻传播学考研学生的辅助学习系统，提供名词解释、简答题、论述题、实务题的背诵与考试训练功能。

当前实现形态（实测基线，详见《新传研背上线前项目审计报告》2026-10-02）：

- **学生端**：纯静态 HTML/JS + Electron 壳，Windows 安装包 73.7MB（5.1.0），学习/考试/AI（自配 Key）本地全流程可用。
- **管理端**：静态页面 + Electron，本地内容编辑与演示工具。
- **后端**：Node 原生 http + JSON 文件存储（公测阶段不部署）。
- **数据**：localStorage + Electron 共享文件 + 服务端 JSON 三套并存（当前以本地为主）。

## 2. 核心模块

### 2.1 背诵模块
- 名词解释：知识框架 + 视频讲解
- 简答题：答题框架 + 关键词记忆
- 论述题：文章结构 + 观点展开

### 2.2 考试模块
- 实务题训练：消息写作 / 新闻评论 / 新闻策划 / 采访分析 / 营销文案 / 健康传播
- 模拟考试（页面已就绪，内容待扩充）
- 考试历史

### 2.3 后台管理平台（本地工具）
- 题库管理（名词解释 / 简答题 / 论述题 / 实务题）
- AI 内容生成（演示模式）
- 内容审核
- 发布管理（演示数据）

## 4. 当前迭代范围（补丁型：仅缺陷修复）

> 本阶段为维护期，**不新增任何功能**。范围以审计报告缺陷清单为准。

### 4.1 本次修复项（5.1.1，GitHub 公测版）

| 编号 | 缺陷 | 验收标准（实测） |
|---|---|---|
| R3 | start-server.js 路径遍历（%2e%2e 编码绕过，可读任意文件） | 路径穿越与编码绕过均返回 403/404 |
| R6 | PWA 安装图标 404 | /assets/app-icon-192.png 返回 200，添加到桌面有图标 |
| R7 | 社区/解析区用户内容未转义（innerHTML 直拼） | 注入 `<img onerror>` 不执行 |
| R8 | Electron 无导航防护 | 外部站点导航被拦截、弹窗被管控 |
| R10 | 管理端 pdf.js 依赖外网 CDN | 断网可解析资料 |
| R11 | preload 文件读写 API 无路径限定 | 越界路径读写被拒绝 |
| R12 | 学习数据无备份，清缓存即丢失 | 导出→清缓存→导入后数据完整 |

### 4.2 范围外（本次不做，归属正式上线阶段）

- R1 真实账号体系（短信/密码 + 服务端会话）
- R2 后端接口鉴权
- R4 管理端→服务端→学生端内容发布闭环
- R5 公网静态资源路径 / Nginx / AI 代理反代
- R9 管理端权限与口令外置
- 一切新功能需求（新题型、新页面、新交互、新模块）
