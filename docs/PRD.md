# 新传研背 V4.0 产品需求文档（PRD）

> 占位文档，后续完善

## 1. 产品概述

新传研背是一款面向新闻传播学考研学生的辅助学习系统，提供名词解释、简答题、论述题、实务题的背诵与考试训练功能。

## 2. 核心模块

### 2.1 背诵模块
- 名词解释：知识框架 + 视频讲解
- 简答题：答题框架 + 关键词记忆
- 论述题：文章结构 + 观点展开

### 2.2 考试模块
- 实务题训练：消息写作 / 新闻评论 / 新闻策划 / 采访分析
- 模拟考试
- 考试历史

### 2.3 后台管理平台
- 题库管理（名词解释 / 简答题 / 论述题 / 实务题）
- AI 内容生成
- 内容审核
- 发布管理
