## 1. 产品概述

新传研背是一款面向新闻传播学考研学生的辅助学习系统，提供名词解释、简答题、论述题、实务题的背诵与考试训练功能。

当前实现形态（2026-10-02 实测基线）：

- **学生端**：纯静态 HTML/JS + Electron 壳（Windows 安装包 5.1.1），PWA 跨端，学习/考试/AI 本地全流程可用。
- **账号体系**：✅ 已实现——手机号+密码登录，未注册自动注册，JWT 会话，游客体验入口。
- **云同步**：✅ 已实现——收藏/笔记/掌握度三类数据云端同步（增量拉取+软删除+冲突后写覆盖），端到端回归测试 PASS。（考试历史接口已预留，客户端暂未接入推送）
- **管理端**：✅ 已实现真实管理员登录（JWT + role 校验）+ 用户管理页（云端真实用户数据）。
- **后端**：✅ 已分层重构——Node 原生 http，routes/auth/db 分离，零第三方运行时依赖；本地 SQLite / 云端 Turso 双模式。
- **部署**：进行中——免费托管后端 + GitHub Releases 分发 + README 下载导航。

## 2. 核心模块

### 2.1 背诵模块
- 名词解释：知识框架 + 视频讲解
- 简答题：答题框架 + 关键词记忆
- 论述题：文章结构 + 观点展开

### 2.2 考试模块
- 实务题训练：消息写作 / 新闻评论 / 新闻策划 / 采访分析 / 营销文案 / 健康传播
- 模拟考试（页面已就绪，内容待扩充）
- 考试历史

### 2.3 后台管理平台（本地工具）
- 题库管理（名词解释 / 简答题 / 论述题 / 实务题）
- AI 内容生成（演示模式）
- 内容审核
- 发布管理（演示数据）
