# 新传研背 V5.0 交互方案（全面交互化 · 功能零变更）

> 版本：V5.0 方案 V1.0 ｜ 编制日期：2026-09-12 ｜ 依据：V4.0 全量代码审计（apps/mobile/app 全部 20 页 + exam.js / practice-v2.js / app.js）
> 一句话定位：**V5.0 不加新功能、不改视觉、不改业务流程，只把 V4 中"看得见但点不动、点了不生效、数据不闭环"的交互补齐，让既有功能从演示态变成可用态。**

## 一、目标与五条铁律

| # | 铁律 | 说明 |
|---|------|------|
| 1 | **功能零变更** | 不改任何既有功能的业务逻辑、页面结构、视觉样式。只"加行为"，不"改外观" |
| 2 | **只补交互不加功能** | 真 AI 调用、真视频、后端账号、整卷模拟等一律不做（见第四节"明确不做"） |
| 3 | **数据本地闭环** | 全部用 localStorage 持久化，沿用既有 key 命名风格，不引入后端与网络依赖 |
| 4 | **复用现有组件** | 弹窗一律走现有 modal 结构与 `showConfirm()`；轻提示新增 `showToast()`（复用同一样式，3 秒自动消失）。不引入任何新 UI 框架 |
| 5 | **可回退** | 每个交互点独立提交、独立可回退；改公共函数时只增分支不改既有分支 |

## 三、交互化实施清单（P0 核心闭环 → P1 一致性 → P2 体验）

> 每项给出：行为定义 / 数据存储 / 改动位置 / 回归风险。共 16 项。

### P0 —— 五条核心闭环（必做）

**I1. 学习统计真实化（解决 G1）**
- 行为：所有学习动作回写统计——自评"认识/模糊/不会"、自测完成、收藏、记笔记、发布分享分别更新对应计数；`studyDays` 按自然日去重累加（记录 `lastStudyDate`）
- 存储：直接更新 `masteredCount / favoriteCount / noteCount / studyDays`（沿用既有 key）；新增 `statBase`（首次升级时把旧默认值 386/57/12 固化为基数，避免数字跳变显得"坏了"）与 `lastStudyDate`
- 位置：app.js 的 handleStatus / completeSelfTest / toggleFavorite / saveNote / submitMemoryMethod 尾部追加回写；首页与个人中心渲染处改为直读真实值
- 回归风险：低（纯追加）。验收：收藏 1 次 → 个人中心"我的收藏"立即 +1，刷新仍在

**I2. 收藏全链路（解决 G2 + G3）**
- 行为：①星标点击 → 写入/移除 `favorites`（结构 `{type, id, title, tag, score, ts}`）；②收藏页改为渲染 `favorites` 真数据（行样式沿用现有 lib-row，视觉不变）；③支持取消收藏（行内星标点击 → showConfirm 确认 → 移除 → 列表刷新）；④空态：无收藏时显示现有空态样式 +「去知识库逛逛」按钮
- 位置：app.js toggleFavorite、collections.html 列表容器 + 新增 renderCollections()（新增函数，不动现有筛选函数）
- 回归风险：中（收藏页列表渲染替换静态行）。对策：保留原 7 条作为"演示数据"仅当 `favorites` 为空且 `demoCollections` 未消费时一次性展示？——**不做**。直接切真数据，首启为空属正常状态，有引导空态。验收：收藏→收藏页出现→取消→消失→刷新状态正确

**I3. 自评与掌握度落库（解决 G4 + G5）**

- 位置：app.js handleStatus、completeSelfTest 弹窗按钮绑定；跳转逻辑一字不改
- 回归风险：低。验收：标记"认识"后 → masteredCount+1 且刷新不丢；重复标记同一词条不重复计数

**I4. 历史训练入口恢复（解决 G6）**
- 行为：考试训练首页顶部标题行右侧加「历史」图标按钮（样式沿用 app-top 现有图标规格，与 V3.0 位置一致——这是**恢复 V3 既有功能**，不是新增）；点击进 exam-history.html；exam-history 渲染 exam_history 真数据 +「继续训练」跳回对应 exam 页 + 空态

- 回归风险：低（纯新增入口，不改考试页任何逻辑）。验收：完成一次采访题作答 → 历史页出现记录 → 继续训练回到原题

## 五、数据层设计

**新增 key（全部 localStorage，命名沿用现有风格）**：

| key | 类型 | 用途 |
|-----|------|------|
| `statBase` | JSON | 一次升级基数 {mastered:386, fav:57, note:12}，防止数字跳变 |
| `lastStudyDate` | 'YYYY-MM-DD' | studyDays 按日累加依据 |
| `favorites` | JSON 数组 | 收藏全链路数据源 |
| `wordRatings` | JSON map | 词条/题目级掌握度（驱动 masteredCount） |
| `lastStudy` | JSON | 继续学习位置 |
| `videoQuality` / `detailLevel` | string | 画质/详略（与 AI 回复长度联动） |
| `aiPromptTemplate` | string | 自定义提示词 |
| `dailyGoal` / `studySpeed` / `offlineSync` / `notifyPush` | string/bool | 学习偏好与系统开关 |
| `localPasswordHint` / `boundEmail` | string | 本机账号信息（明示仅本机生效） |
| `feedbacks` | JSON 数组 | 意见反馈记录 |
| `APP_VERSION` | 'v5.0.0' | 关于页动态版本 |

**兼容与迁移**：首启检测 `statBase` 不存在 → 写入旧默认基数；`favorites` 不存在 → 空数组（收藏页走空态）。所有读取沿用 `|| 默认值` 风格，旧版本数据无需迁移脚本。
