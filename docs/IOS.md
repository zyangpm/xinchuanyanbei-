# iPhone（iOS）使用教程

> 苹果系统不允许直接安装 .apk / .exe 安装包。新传研背用 **PWA（渐进式网页应用）** 方案：Safari 打开 →"添加到主屏幕"，体验与原生 App 一致（桌面图标、全屏、注册登录、云同步）。

## 前提

- 学生端地址：https://app-three-orpin-61.vercel.app
- iPhone 系统 iOS 14.0 及以上

## 安装步骤（约 30 秒）

1. **打开链接**：在 iPhone 自带 **Safari 浏览器**（不是微信/QQ 内置浏览器）打开新传研背网址，进入后先**注册登录**一个账号
2. **添加到主屏幕**：点浏览器底部中间的**分享按钮**（方框+向上箭头）
3. **下滑选择**：在分享菜单里找到并点击 **"添加到主屏幕"**
4. **确认**：名称保持"新传研背"，点右上角 **"添加"**
5. **完成**：回到手机桌面，会出现"新传研背"图标，点开即全屏使用，和原生 App 一样

## 使用提示

- 登录后收藏/笔记/掌握度自动云同步，换设备登录同一账号数据自动恢复
- 首次打开建议联网使用；离线时仍可背诵本地内容，联网后自动同步
- 想删除：长按桌面图标 → "移除 App"（云端数据不受影响，重新添加即可）

## 常见问题

| 问题 | 解决 |
|---|---|
| 微信里打不开 / 跳转异常 | 复制链接到 Safari 打开 |
| 点分享找不到"添加到主屏幕" | 确认用的是 Safari（Chrome/微信无此选项） |
| 提示需要登录 | 先注册一个手机号+密码账号（未注册自动创建） |
