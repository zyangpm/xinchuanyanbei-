# 新传研背 V1.0 - 手机使用方法

## ⚠️ 关于 iPhone APP 安装包

**在 Windows 电脑上无法生成 iPhone APP 安装包（.ipa）**，这是苹果公司的技术限制：
- iOS APP 必须在 Mac 电脑上用 Xcode 编译
- 需要 Apple 开发者账号（$99/年）

**但可以用 PWA（网页APP）方式**，体验和真正 APP 几乎一样：有图标、全屏运行、可以切换。

---

## 📱 手机使用步骤（超级简单）

### 第1步：在电脑上启动服务

双击运行：
```
新传研背_V1.0\启动网页版.bat
```

启动后：
- 电脑浏览器会**自动打开**二维码页面
- 不要关闭弹出的黑色窗口（关闭则服务停止）

### 第2步：手机扫码

用手机相机或微信扫描电脑屏幕上的二维码，手机会自动打开新传研背。

### 第3步：添加到手机桌面（像APP一样用）

**iPhone 用户：**
1. 用 **Safari** 打开链接（必须用Safari）
2. 点底部中间的"分享"按钮（向上箭头↑）
3. 向下滑找到"添加到主屏幕"
4. 点"添加"，桌面出现"新传研背"图标
5. 以后点图标就能用，和真APP一样

**Android 用户：**
1. 用 Chrome 打开链接
2. 点右上角三点菜单
3. 选"添加到主屏幕"
4. 桌面出现"新传研背"图标

## 📋 完整使用说明

| 功能 | 怎么用 |
|------|--------|
| 电脑用APP | 双击 `学生端APP\新传研背.exe` |
| 手机用APP | 双击 `启动网页版.bat` → 手机扫码 |
| 管理后台 | 双击 `管理后台\新传研背管理后台.exe` |
| 管理后台（手机） | 启动网页版后，手机访问 `http://[电脑IP]:8080/admin/` |

## ❓ 常见问题

**Q：手机扫不了码？**
A：确认电脑和手机连同一个WiFi，检查电脑防火墙是否允许8080端口。

**Q：网页版和APP有区别吗？**
A：功能完全一样，PWA添加到桌面后体验和APP一样。

**Q：服务启动不了？**
A：需要安装 Node.js（如果没装），去 nodejs.org 下载安装。

**Q：关掉电脑后手机还能用吗？**
A：不能，需要电脑开着并运行"启动网页版.bat"。如果要24小时使用，需要部署到服务器。
