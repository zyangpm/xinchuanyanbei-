## 归档说明

- V1.0 已有较完整的界面截图归档，适合作为旧版功能对照和历史留档。
- V2.0 已有版本说明归档，但界面截图仍需确认是否完整，建议保留桌面原始目录直到确认无遗漏。
- 若需清理旧版桌面目录，请先核对版本目录中的截图是否完整，再删除原始备份文件。

## 建议操作顺序

1. 先保留 V2.0 原始目录，确认所有关键页面截图已完整归档。
2. 当 V1.0 与 V2.0 的界面截图均确认无缺失后，再删除桌面上的旧版源文件。
3. 已上传到 GitHub 的版本目录可作为长期档案，建议保留。
