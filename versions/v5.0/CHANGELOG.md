# V5.0 更新日志

## [5.0] - 2026-09-13 交互化版本

### 版本定位

在 V4.0 Monorepo 架构基础上做"交互化"：把 V4 中仅作展示的静态数据、演示按钮、占位设置全部接通为真实可交互逻辑，并实现学生端与管理后台的数据联动。**现有功能、页面视觉、题库内容零变更**，不接真实网络 API，不新增页面与题型。

### 一、学习数据闭环

1. **I1 学习统计真实化**
   - 新增 `statBase` 一次升级基数（已背 386 / 收藏 57 / 笔记 12），升级首启数字不跳变
   - 新增 `bumpStat()`：收藏、笔记、自评等操作后计数真实增减并持久化
   - 新增 `markStudyDay()`：按自然日去重累加学习天数，同一天多次学习只计一次

2. **I2 收藏全链路**
   - `toggleFavorite` 真实落库 `favorites`，详情页星星状态 `initFavoriteStar` 回显
   - 收藏页改为 `renderCollections()` 动态渲染真实收藏数据，保留原有全部/名词/简答/论述筛选
   - 支持取消收藏、空态引导（"去知识库逛逛"）

3. **I3 自评 / 自测掌握度落库**
   - 新增 `wordRatings` 存储，掌握度评价（认识/模糊/不认识）随词条持久保存
   - 同一词条反复自评不重复计数，自测完成后进度可见变化

### 二、入口恢复与设置中心

4. **I4 历史训练入口恢复**
   - 考试训练首页右上角恢复时钟图标"历史训练"入口，进入 exam-history.html 查看真实训练记录

5. **I5 设置中心激活（含 L1 反馈上行）**
   - 账号管理：修改密码、绑定邮箱、退出登录等交互接通并持久化
   - 学习偏好、AI 模型、系统通用、关于等分区全部展示真实数据并可操作
   - 意见反馈按管理后台既有字段结构写入 `feedbacks`，提交后提示"已同步至管理后台"
   - 缓存清理真实计算 localStorage 占用，核心学习数据白名单保护

6. **I6 深色模式三档**
   - 恢复 V3 既有深色能力：跟随系统 / 深色 / 浅色，偏好持久化，复用现有 dark 变量

### 三、AI 一致性与体验补全

7. **I7 AI 助记动态化**：四个提问模板与 AI 回复中硬编码的"沉默的螺旋"全部改为当前词条插值，不同词条不再串词
8. **I8/I9 AI 设置生效**：生成画质、文字详略选择持久化保存并实际影响生成表现
9. **I10 思维导图标题联动**：切换词条后导图标题随当前词条更新（缺陷修复）
10. **I11 统一轻提示**：新增 `showToast()` 用于收藏/保存/切换等轻反馈，既有 showConfirm 全部保留
11. **I12 空态补全**：收藏为空、知识库搜索无结果时展示统一空态（图标 + 文案 + 引导按钮）

### 四、管理后台联动（L1–L3）

12. **L1 反馈上行闭环**：学生端反馈 → 管理后台"用户反馈"页即时可见（后台零改动）
13. **L2 学习数据上行**：管理后台"数据统计"页新增"学生端学习数据"卡片区：已背词条 / 收藏 / 笔记 / 连续学习天数 / 考试训练次数，全部读学生端真实 key，只读展示，不影响后台既有内容统计
14. **L3 资料双向互通**：学生端"自建资料收藏"入口激活，资料库与管理后台共用 `xc_materials`，分"后台发布（只读，可查看/下载）"与"我的自建（可查看/下载/删除）"两组；后台增删改后学生端刷新即可见

### Bug 修复

- 修复 `submitFeedback` 在 app.js 中重复定义、后定义覆盖前定义导致意见反馈点击提交静默失败的问题，合并为同时兼容两个反馈弹窗的单一实现（V5.0 回归测试发现并复测通过）
- 静态服务增加 `Cache-Control: no-cache` 响应头，避免开发/测试时浏览器缓存旧版 HTML/JS

### 明确不做（负面清单）

- 不接真实 AI API、不做真实视频生成/上传及任何网络请求型功能
- 不做真实注册/短信/第三方 OAuth，沿用模拟登录
- 不做整卷模拟考试，不新增题型与页面，不改任何页面视觉
- 不重构现有函数签名，不换技术栈，不动题库数据内容
