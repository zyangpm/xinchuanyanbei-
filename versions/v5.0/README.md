# V5.0 - 交互化版本

V5.0 在 V4.0 Monorepo 架构（apps/mobile + apps/admin + packages/content）之上完成"交互化"：静态展示接通真实数据与操作，学生端与管理后台通过 localStorage 实现反馈、学习统计、资料三类数据联动。现有功能、页面视觉、题库内容保持不变。

## 核心内容

- **学习数据闭环**：学习统计真实化（基数迁移不跳变）、收藏全链路落库、自评/自测掌握度持久化
- **入口与设置**：恢复历史训练入口；设置中心账号/偏好/AI/通用/反馈全分区激活；深色模式三档（跟随系统/深色/浅色）
- **AI 一致性**：AI 模板与回复随当前词条动态化，画质/详略设置持久化生效
- **管理后台联动**：
  - L1 意见反馈学生端提交 → 后台"用户反馈"即时可见
  - L2 后台"数据统计"新增学生端学习数据卡片（已背/收藏/笔记/天数/训练次数）
  - L3 资料库双向互通（`xc_materials` 同库，后台发布只读、学生自建可删）
- **体验补全**：统一 toast 轻提示、收藏/搜索空态引导、思维导图标题联动修复

详见 [CHANGELOG.md](CHANGELOG.md)，交互设计与审查过程见 [../../docs/V5.0交互方案与审查.md](../../docs/V5.0交互方案与审查.md)。
