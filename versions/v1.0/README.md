## 版本回顾

V1.0 的核心特征是：

- 以“内容学习 + 题目背诵 + 学习记录”作为主路径；
- 打通了移动端学习场景与基础知识梳理功能；
- 引入了 AI 模型设置、自动播放和个性化学习配置；
- 早期交互风格偏“知识卡 + 题目回顾 + 解释说明”，更偏教学型产品原型。

这个版本是后续版本迭代的基础模板，也是历史留档中最值得保留的原始界面状态之一。
