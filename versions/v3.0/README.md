# V3.0 考试训练版（学生端 APP 实机截图）

V3.0 在 V2.0「背诵闭环 + 管理后台内容流水线」的基础上，把产品明确拆成**背诵学习**与**考试训练**两条独立主线：
首页新增第 5 个核心入口「考试训练」，内置实务题 / 理论题 / 模拟考试三个标签，按考场题型分阶段专项训练；
同时补齐了 V1.0、V2.0 相册中从未出现过的**登录 / 注册体系**（密码登录、验证码登录、三方登录），
个人中心新增昵称修改、学习模式切换、资料库下载管理，API 密钥、深色模式、版本反馈等在 V2.0 标注「开发中」的功能本版本全部落地。

> 截图说明：以下共 **51 张**，均为 2026-09-11 对 V3.0 学生端 APP 真实运行界面的手工截图，无重复过程图，
> 已按用户实际操作路径（首页 → 登录与个人中心 → 名词解释「新闻价值」→ 简答题「霍尔编码解码模型」→
> 论述题模板库 → 实务题训练 → 考试训练全流程）排列，平铺于 `screenshots/`。
> 本版本无新的管理后台截图，后台沿用 V2.0；每张图的说明中直接注明与 V1.0 / V2.0 的异同，不再另设区别专节。

### 37. 新闻采访题 · 考生作答

「考生作答」tab 把参考答案拆成「一、采访任务目的」「二、人员安排」等分段填空卡，每段带灯泡形「AI 思路」提示，由考生逐段动笔；底部两个金色按钮「查看我的答案汇总」「查看完整答案」。这种分段作答 + AI 思路的考练形式在 V1.0/V2.0 中不存在。

### 39. 新闻评论题 · 答题框架（第 1/3 题）

第二阶段题型。材料为某网红奶茶品牌使用过期原料、篡改保质期，要求写 300 字短评。框架表为「新闻评论根本三大特征」：论题新闻性、论理思想性、论说公众性，每行附标准答题话术。对比 V2.0 相册第 32 张背诵侧评论题（标题 / 引论 / 本论卡片式框架），考试侧框架是更适合速记速查的表格。

### 40. 新闻评论题 · 考生作答（标题与引论）

## 版本小结

V3.0 以「考试训练」独立成模块为核心：背诵侧延续 V1.0/V2.0 成熟的视频 → 框架 → 分层记忆 → 自测自评闭环并修复了 V2.0 的两处显示瑕疵，考试侧新建了「框架表 + 分段作答 + AI 思路 + 用户分析 + 答案汇总 + 历史续训」的考场化训练链路；登录注册体系、账号资料管理与深色模式等基础能力在本版本补齐，理论题与全真模拟为下一阶段预留了入口。
