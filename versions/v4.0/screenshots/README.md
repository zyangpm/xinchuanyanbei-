# V4.0 截图归档说明

本目录用于归档 V4.0 的界面截图，遵循 V1.0 / V2.0 的整理逻辑：

- 统一按“管理员端”和“学生端”两大模块存放
- 每张图都按页面功能区分命名
- 每个模块补充说明，明确截图目的、页面状态和重点信息
- 不复制旧版本图片内容，不做一字不差的模仿，而是按同一归档思路进行新版记录

## 目录结构

```text
screenshots/
├── admin/        # 管理后台截图
├── app/          # 学生端 APP/网页截图
└── README.md     # 当前说明文件
```

## 截图原则

1. 以“功能展示”为主，不收集重复的中间状态图
2. 保留关键页面，如登录页、首页、核心模块页、重要设置弹窗
3. 每张截图都需要对应明确说明：
   - 页面名称
   - 进入路径
   - 重点功能
   - 版本特征
4. 跟随 V4.0 的架构标准化特征：
   - app/mobile
   - app/admin
   - packages/content
   - Monorepo 结构清晰度优先
