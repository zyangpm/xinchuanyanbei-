# V4.0 学生端截图说明

本目录用于归档 V4.0 学生端 APP / 网页端的核心界面截图，重点展示本版本的学习主流程与交互状态。

## 建档思路

沿用 V1.0 / V2.0 的截图整理方法，但不复制旧版本的同类页面截图。V4.0 的重点是：

- 架构标准化后的页面统一性
- 学生端多模块学习闭环
- 题库数据与课程内容的统一展示
- 主题、字体、学习模式与收藏机制的一致性

## 截图注释方向

### 01-home.png
首页，展示学习入口、继续学习卡片和核心功能模块。

### 02-knowledge.png
知识学习页，展示知识类内容入口和学习资源组织方式。

### 03-noun-detail.png
名词解释详情页，展示词条框架、视频、记忆方式和 AI 辅助模块。

### 04-short-detail.png
简答题详情页，展示答题框架、答案内容和辅助记忆。

### 05-essay-detail.png
论述题详情页，展示题目结构、范文和答题方法。

### 06-practice-list.png
实务题列表页，展示题型分类和题目入口。

### 07-practice-detail.png
实务题详情页，展示题目、框架结构和用户答案编辑区。

### 08-exam-home.png
考试训练首页，展示练习入口和考试模式切换入口。

### 09-profile.png
个人中心页，展示用户信息、学习数据和账号状态。

### 10-settings.png
设置页，展示主题、字体、提醒和用户偏好配置。

## 说明

此目录仅用于 V4.0 的学生端截屏归档，不与 V1.0 / V2.0 / V5.0 互相混用。后续新增版本时，按对应版本目录独立管理即可。
