# V4.0 管理后台截图说明

本目录用于归档 V4.0 管理后台的真实使用流程截图，按照“用户登录 -> 进入后台 -> 逐级点击导航 -> 查看各功能页”的顺序整理。

## 建档思路

沿用 V1.0 / V2.0 的页面归档逻辑，但不复制旧版本截图内容；重点保留本版本在 Monorepo 架构下的后台使用路径：

- 登录页与管理员权限入口
- 数据概览页
- 资料管理页
- AI 生成页
- 题库管理页
- 发布管理页

## 截图注释方向

### 01-login.png
管理员登录页，展示后台入口和登录表单。

### 01-login-filled.png
按真实用户操作：输入 admin / admin123 后的登录状态截图，说明用户流程从登录开始。

### 02-dashboard.png
登录后进入数据概览页，展示后台核心指标与待审核内容。

### 03-material-list.png
资料管理页，展示资料列表、来源筛选和后台资料流转入口。

### 04-ai-generate.png
AI 生成页，展示资料生成题目、生成规则和参数选择。

### 05-question-bank.png
题库管理页，展示题目列表、筛选和后台题库维护入口。

### 06-publish-manage.png
发布管理页，展示内容发布流程和发布状态。

## 说明

本目录不修改 V1.0 / V2.0 / V3.0 的历史截图，且仅用于 V4.0 的后台使用流程归档。后续新增版本请另建对应版本目录，不在当前目录中继续叠加历史截图。
