# V4.0 架构标准化版（学生端 APP 实机截图）

V4.0 在 V3.0「背诵学习 + 考试训练」双主线的基础上完成**架构标准化**：代码层重构成 Monorepo（`apps/mobile` 学生端 + `apps/admin` 管理后台 + `packages/content` 题库数据包）；
产品层则把两条主线在导航上进一步固化——底部导航由首页 / 知识库 / 收藏三栏扩为**首页 / 知识库 / 收藏 / 考试 / 我的五栏**，「考试训练」不再是首页第五张卡片，而是常驻底部 tab；
个人中心从 V3.0 的弹窗堆叠改为**「我的」页 + 设置中心分区**（账号管理 / 学习偏好设置 / 自建资料收藏 / AI 模型自定义管理 / 系统通用设置 / 意见反馈·关于 App）；
V3.0 相册中标注「功能预留」的生成画质、文字详略，以及 API 模型管理，在 V4.0 已配齐可用（设置中心显示 GPT-4 已配置 + 自定义提示词模板，词条页可切换 DeepSeek / GPT / Claude / Gemini 并选画质与详略）。

> 截图说明：以下共 **57 张**，均为 2026-09-12 对 V4.0 学生端 APP 真实运行界面的手工截图，无重复文件，
> 已按用户实际操作路径（首页 → 个人中心与设置 → 收藏 → 名词解释「新闻价值 / 传播 / 受众」→ 简答题「霍尔编码解码模型」→
> 论述题「媒介素养」→ 实务题「消息写作」→ 考试训练采访题 / 评论题 / 模拟考试）排列，平铺于 `screenshots/`。
> 本版本无新的管理后台截图，后台沿用 V2.0 相册（V4.0 仅将其代码迁入 `apps/admin`，界面与功能未变）；

## 版本小结

V4.0 以「架构标准化」为主题：代码层完成 Monorepo 拆分（apps/mobile + apps/admin + packages/content），产品层用五栏底部导航把背诵与考试两条主线彻底固定——考试训练从首页卡片降为常驻 tab，个人中心升级为「我的 + 设置中心」分区结构；V3.0 的「功能预留」项（生成画质 / 文字详略 / AI 模型管理）全部落地并支持 GPT-4 与自定义提示词，词条视频开始真实可播，自测完成与学习进度形成闭环，收藏页首次以分值标签形式示人，简答 / 论述题新增分值字数徽标与完整范文，考试侧采访题框架扩充至「两种分类 + 周全准备 + 完整计划模板」三段。背诵闭环（视频 → 框架 → 导图 → 自测 → 进度）与考试链路（框架 → 分段作答 → AI 思路 → 汇总 → 用户分析）在本版本双双成型。
