### v1.0.0 (2026-07-25)

#### 界面优化

1. **应用名称统一**

3. **底部导航优化**
   - 活动状态改为深色背景+白色文字

     - 知识库：深蓝色书本 + 白色线条
     - 收藏：金色星星

4. **搜索框样式完善**
   - 添加搜索图标容器和放大镜图标
   - 调整搜索框内边距以容纳图标

5. **首页用户卡片样式**
   - 改为深色背景横向布局
   - 头像改为红色圆形背景

#### 结构优化

2. 构建输出目录从dist/改为build/（避免文件占用冲突）

- 所有原有功能模块和交互逻辑保持不变
- 页面导航、头像交互、设置开关等功能正常运行

### 项目结构说明

```
新传软件/
├── assets/           # 静态资源（图标）
├── renderer/         # 渲染进程文件（HTML/CSS/JS）
├── admin/            # 管理后台源码
├── start-server.js   # 网页版服务器
├── main.js           # 主进程入口
├── admin-main.js     # 管理后台主进程入口
├── preload.js        # 预加载脚本
├── package.json      # 项目配置
└── package-lock.json # 依赖锁定
```
